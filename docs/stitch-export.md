# Stitch Export Inventory

The local Stitch reference bundle contains four implementation screens plus the shared control-room design notes:

- `main_council_view`: primary council arena source and capture
- `onboarding_first_launch`: first-launch source and capture
- `agent_detail_ledger`: Ledger detail source and capture
- `dashboard_configuration`: dashboard source and capture
- `hermes_council_control_room/DESIGN.md`: palette, typography, spacing, and interaction guidance

These files are references for the Electron implementation and are kept separate from runtime assets.
