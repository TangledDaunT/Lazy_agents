# Configuration

Required live-response settings:

- `HERMES_GATEWAY_URL`, default `http://localhost:8642`
- `HERMES_API_KEY`, when the gateway requires authentication
- `OBSIDIAN_VAULT_PATH`, optional Markdown vault location
- `PIPER_BIN` and `PIPER_VOICES_DIR`, optional speech synthesis settings
- `PYTHON_BIN`, optional Python interpreter override

Agent routing, names, and voice filenames live in `agents_config.json`.
