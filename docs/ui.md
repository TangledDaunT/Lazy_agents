# UI Guide

The main window uses the Stitch Hermes Council control-room direction: obsidian surfaces, glass panels, gold Hermes accents, and specialist spectrum colors.

The center arena selects an agent. The bottom command dock sends to one specialist or the full council. The left feed shows activity and the right workspace switches between vault, shared context, and council output.

The dashboard edits display names, wake words, Piper voices, and skins.
